# Portfólio Pessoal com CSS — C2

**Aluno:** George Pinheiro Ramos  
**Atividade:** C2 — Portfólio Pessoal com CSS  
**Entrega:** 30/10/2026

Este projeto amplia o portfólio em HTML do repositório original, adicionando CSS externo e layout responsivo.

## Arquivos

- `index.html`: estrutura semântica, navegação e conteúdo.
- `style.css`: aparência e técnicas da Unidade 2.
- `foto-perfil.jpg`: **manter a imagem que já existe no repositório**; não está incluída neste pacote.

## Conteúdos aplicados da Unidade 2

1. **Seletores e cascata:** seletores de elemento, classe, descendentes e pseudoclasses `:hover`, `:focus-visible`; variáveis CSS e herança.
2. **Box model:** `box-sizing`, `margin`, `padding`, `border` e tamanhos adaptáveis.
3. **Posicionamento:** cabeçalho `position: sticky` e link de acessibilidade `position: absolute`.
4. **Flexbox:** navegação, seção inicial, habilidades, projetos e rodapé.
5. **Responsividade:** `viewport`, unidades relativas, `clamp()` e `@media` em 760 px e 420 px.
6. **Acessibilidade:** idioma do documento, HTML semântico, texto alternativo da fotografia, navegação via teclado, link para pular ao conteúdo, foco visível, contraste e preferência de movimento reduzido.
